# Data Model: GitHub Issues CLI Command

**Feature**: 001-github-issues-cli
**Date**: 2026-01-06

## Entities

### ExtractedBug

Bug information extracted from an analysis report.

| Field | Type | Description |
|-------|------|-------------|
| `source_file` | `str` | Path to analyzed file (e.g., `src/core/analyzer.py`) |
| `report_file` | `str` | Path to analysis report markdown |
| `bug_type` | `str` | One of: `security`, `risk`, `inconsistency`, `suggestion` |
| `severity` | `str` | One of: `critical`, `high`, `medium`, `low` |
| `title` | `str` | Brief description (first line of bug text) |
| `description` | `str` | Full bug description |
| `recommendation` | `str` | Suggested fix (if available) |
| `line_number` | `Optional[int]` | Line number in source file |
| `code_snippet` | `Optional[str]` | Relevant code excerpt |

**Validation Rules**:
- `source_file` must be a valid path format
- `bug_type` must be one of the 4 valid types
- `severity` must be one of the 4 valid levels
- `title` max length: 100 characters (GitHub title limit)

---

### IssueOptions

Configuration options for the issues command.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `dry_run` | `bool` | `False` | Preview without creating issues |
| `labels` | `List[str]` | `[]` | Additional custom labels |
| `assignee` | `Optional[str]` | `None` | GitHub username to assign |
| `repo` | `Optional[str]` | `None` | Target repo (owner/repo format) |
| `from_report` | `Optional[str]` | `None` | Specific report file path |

---

### IssueToCreate

Issue prepared for GitHub creation.

| Field | Type | Description |
|-------|------|-------------|
| `title` | `str` | Issue title: `[{BugType}] in {filename} - {brief}` |
| `body` | `str` | Formatted markdown body |
| `labels` | `List[str]` | Combined default + custom labels |
| `assignee` | `Optional[str]` | GitHub username |
| `bug` | `ExtractedBug` | Source bug reference |

**Title Format**: `[{bug_type.title()}] in {filename} - {title[:50]}`

**Body Template**:
```markdown
## File

`{source_file}`

## Bug Description

{description}

## Issue Details

- **Type**: {bug_type}
- **Severity**: {severity}
- **Line**: {line_number or "N/A"}

## Recommended Solution

{recommendation}

## Code Context

```{language}
{code_snippet}
```

---
*Generated by [Aetheris](https://github.com/adryserage/aetheris) code analysis*
```

---

### IssueResult

Result of a single issue creation attempt.

| Field | Type | Description |
|-------|------|-------------|
| `status` | `str` | One of: `created`, `skipped`, `failed` |
| `title` | `str` | Issue title |
| `url` | `Optional[str]` | GitHub issue URL if created |
| `error` | `Optional[str]` | Error message if failed |
| `bug` | `ExtractedBug` | Source bug reference |

---

### IssuesSummary

Final summary of the issues command execution.

| Field | Type | Description |
|-------|------|-------------|
| `total_bugs` | `int` | Total bugs found in reports |
| `created` | `int` | Issues successfully created |
| `skipped` | `int` | Issues skipped (already exist) |
| `failed` | `int` | Issues that failed to create |
| `results` | `List[IssueResult]` | Individual results |
| `duration_seconds` | `float` | Total execution time |

---

## State Transitions

```
ExtractedBug → IssueToCreate → IssueResult
     ↑              ↓              ↓
   parse()      format()      create()
```

1. **Parse**: Markdown → `ExtractedBug` list
2. **Format**: `ExtractedBug` → `IssueToCreate` (add labels, format body)
3. **Create**: `IssueToCreate` → `IssueResult` (call gh CLI, handle result)
