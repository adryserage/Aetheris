# Implementation Plan: GitHub PR Generator

**Branch**: `002-github-pr-generator` | **Date**: 2026-01-06 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/002-github-pr-generator/spec.md`

## Summary

Create a CLI command `aetheris pr` that generates Pull Requests for each bug found in analysis reports. The system will reuse bug parsing from `issue_creator.py`, generate AI-powered fixes using the existing AI providers, create git branches, commit fixes, and open PRs via the `gh` CLI.

**Primary Dependencies**:
- Rich (console output, already installed)
- subprocess (git and gh CLI operations)
- Existing AI providers (`src/core/ai_providers.py`)
- Existing issue_creator (`src/services/issue_creator.py` for bug parsing)

**Storage**: N/A (uses git and GitHub)
**Testing**: Manual testing with `--dry-run` flag
**Target Platform**: Linux/macOS/Windows CLI
**Project Type**: Single project (extends existing Aetheris CLI)
**Performance Goals**: Generate 20 PRs in under 5 minutes
**Constraints**: Rate limiting from GitHub API, AI token limits per request
**Scale/Scope**: Process up to 50 bugs per analysis run

## Key Design Decisions

### 1. Reuse from issue_creator.py
- Import `ExtractedBug` dataclass
- Import `IssueCreator.parse_reports()` and `parse_single_report()` methods
- Share bug type classification and severity extraction logic

### 2. AI Fix Generation Strategy
- Read source file content
- Build prompt with: bug description, code context, recommendation
- Request AI to generate minimal fix (diff format or full replacement)
- Validate generated code with Python syntax check

### 3. Git Operations Flow
```
1. Validate base branch exists
2. For each bug:
   a. Create branch: fix/<type>-<file>-<hash>
   b. Read source file
   c. Generate AI fix
   d. Apply fix to file
   e. Validate syntax
   f. Commit with conventional message
   g. Push branch
   h. Create PR via gh CLI
   i. Restore original file state
3. Return to original branch
```

### 4. Branch Naming Convention
Format: `fix/<bug-type>-<filename>-<short-hash>`
Example: `fix/security-analyzer-abc123`

### 5. PR Body Template
```markdown
## Description
[AI-generated summary of the fix]

## Changes Made
- [List of changes]

## Related Issue
Fixes #<issue_number> (if linked)

## Testing Notes
- [ ] Syntax validated
- [ ] Manual review recommended

---
*Generated by [Aetheris](https://github.com/adryserage/aetheris) PR Generator*
```
